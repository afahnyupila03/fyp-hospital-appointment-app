# 🏥 Hospital Appointment System

A complete hospital scheduling and appointment management system with real-time updates, role-based dashboards, and automated workflows.

Designed for hospitals needing a modern digital booking experience.

---

## 🚀 Features

- **Role-based access**
  - Admin  
  - Doctor  
  - Patient  

- **Appointment Management**
  - Booking  
  - Updating  
  - Cancelling  
  - Doctor availability  
  - Consultation status tracking  

- **Notifications**
  - Email or in-app  
  - For appointment confirmations, updates, or cancellations  

- **Charts & Analytics**
  - Doctor dashboards  
  - Appointment status graphs  

---

## 🧱 Tech Stack

**Frontend:** Next.js
**Backend:** Node.js, Express  
**Database:** MongoDB
**Auth:** JWT  
**UI:** Tailwind / Custom
